# Day 3 – Combinational and Sequential Logic

## Overview
This repository contains my Day 3 work from the **SKY130 RTL Design and Synthesis Workshop**. The focus is on understanding combinational logic, sequential logic, and sequential optimization using Verilog HDL and Yosys.

## Topics Covered

### 1. Introduction to Combinational Logic
- Introduction to combinational logic concepts.
- Understanding combinational circuit design.

### 2. Combinational Logic – Lab 06
- Combinational logic design experiments.
- RTL coding and synthesis.
- Understanding logic optimization.

### 3. Sequential Logic – Lab 07
- Introduction to sequential logic.
- Sequential circuit design using Verilog.
- RTL simulation and synthesis experiments.

### 4. Sequential Optimization
- Introduction to sequential optimization.
- Optimization of sequential circuits.
- Analysis of synthesized designs.

## Tools Used
- Verilog HDL
- Yosys
- SKY130 Standard Cell Library
- Icarus Verilog
- GTKWave
- Ubuntu Linux

## Key Learnings
- Understood the basics of combinational and sequential logic.
- Practiced RTL design using Verilog HDL.
- Explored sequential circuit implementation.
- Learned about sequential optimization.
- Gained practical experience with RTL synthesis using Yosys.
