# SKY130 RTL Design and Synthesis Workshop

## Overview
This repository contains my work and practical experiments from the 5-day RTL Design and Synthesis Workshop using the SKY130 PDK, conducted by VLSI System Design (VSD).

The workshop focuses on Verilog RTL design, simulation, synthesis, gate-level simulation, and synthesis optimization.

## Day-wise Progress

### Day 1 – Introduction to Verilog RTL Design
- Introduction to Verilog and RTL design.
- Simulation and synthesis basics.
- Understanding Verilog coding styles.

### Day 2 – Timing Libraries, Hierarchical Design and Flip-Flops
- Introduction to timing libraries.
- Hierarchical versus flat design.
- Various flip-flop concepts.
- Asynchronous and synchronous reset experiments.

### Day 3 – Combinational and Sequential Logic
- Combinational logic design.
- Sequential logic design.
- RTL coding and synthesis experiments.
- Sequential circuit optimization.

### Day 4 – GLS, Blocking vs Non-Blocking
- Gate-Level Simulation (GLS).
- Blocking and non-blocking assignments.
- Synthesis and simulation mismatches.
- Understanding RTL coding behavior.

### Day 5 – Optimization in Synthesis
- If-case constructs.
- Incomplete and overlapping case statements.
- For loops and generate statements.
- Synthesis optimization and gate-level analysis.
